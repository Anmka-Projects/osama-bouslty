# واجهة سلايدر التطبيق (لـ Flutter)

وثيقة لربط تطبيق الجوال بسلايدر الصفحة الرئيسية.

**مهم:** التطبيق يستقبل **السلايدرات المفعّلة فقط** (`isActive = true`). أي سلايدر معطّل في لوحة التحكم **لا يُرسل أصلًا** في هذا الـ API ولا يظهر في الاستجابة.

---

## العنوان الأساسي (Base URL)

```text
https://elsherifacademy.anmka.com/api
```

(أو البيئة المناسبة — المسار `/api` عبر Next.js نحو الـ backend.)

---

## جلب السلايدر للعرض (عام — بدون تسجيل دخول)

**الطريقة:** `GET`  
**المسار:** `/sliders`  
**العنوان الكامل:** `{BASE_URL}/sliders` مثل `https://.../api/sliders`  
**الصلاحيات:** لا تتطلب `Authorization`.

### الاستجابة الناجحة

كل عنصر في `data` هو سلايدر **مفعّل** حاليًا. لا يوجد حقل `isActive` في الاستجابة (غير مطلوب لأن القائمة كلها مفعّلة).

```json
{
  "success": true,
  "data": [
    {
      "id": "uuid",
      "image": "/uploads/images/....jpg",
      "createdAt": "2026-05-03T12:00:00.000Z"
    }
  ]
}
```

- **`id`:** مُعرّف فريد.
- **`image`:** مسار نسبي أو URL كامل. لبناء الرابط في Flutter:
  - إذا بدأ بـ `http` استخدمه كما هو.
  - وإلا اربطه بنطاق الموقع + المسار (مثل `https://elsherifacademy.anmka.com` + `image`).
- **`createdAt`:** وقت الإنشاء (ISO 8601) — الترتيب في الـ backend من الأحدث إلى الأقدم.

### أخطاء

`success: false` مع `message` (نص عربي) عند الفشل.

## ملاحظات Flutter

1. `GET` إلى `$apiBase/sliders` حيث `apiBase` ينتهي بـ `/api`.
2. لا تفترض وجود سلايدرات معطّلة في القائمة — **لا تُرسل**.
3. الصور: `NetworkImage` / `cached_network_image` مع الرابط الكامل بعد الدمج إن لزم.

## لوحة التحكم (مرجع للأدمن فقط)

| الإجراء | الطريقة | المسار |
|--------|---------|--------|
| كل السلايدرات (مفعّل + معطّل) | GET | `/admin/sliders` |
| إنشاء | POST | `/admin/sliders` — `{ "image": "...", "isActive": true \| false }` |
| تحديث | PUT | `/admin/sliders/{id}` |
| حذف | DELETE | `/admin/sliders/{id}` |

التطبيق يستخدم **فقط** `GET /api/sliders` أعلاه.
